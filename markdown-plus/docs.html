Mermaid, Markdown & LaTeX

Documentation for the Confluence app

Adding a diagram or document

  1. Edit a Confluence page
  2. Type /Mermaid and pick Mermaid & Markdown
  3. Write in the left pane. The right pane updates as you type
  4. Save, then publish the page

The source you write is stored inside the macro. It travels with the macro when you copy the page, move it, or include it somewhere else.

What you can write

Anything Markdown, plus three additions.

Mermaid diagrams

Fence a block with mermaid:

```mermaid
graph LR
  Commit --> CI
  CI --> Deploy
```

Flowcharts, sequence, class, state, ER, Gantt, pie, journey, mindmap and the rest of the mermaid grammar all work. One macro can hold several diagrams.

Code

Fence with a language name for syntax highlighting. 29 languages are supported, covering the common ones (JavaScript, TypeScript, Python, Java, Go, Rust, C, C++, C#, Ruby, PHP, SQL, Bash, YAML, JSON, HTML, CSS and others).

Moving off another mermaid app

If your diagrams currently sit in plain code blocks — how the Atlassian Labs viewer and several other apps work — there is a converter.

  1. Open the page
  2. ⋯ → Apps → Convert mermaid code blocks
  3. It tells you how many it found and exactly what it will change
  4. Convert page

What it does:

  • Every mermaid code block becomes a macro holding its own source
  • Other code blocks and all other content are left alone
  • The result is saved as a new page version, so the original stays in your

page history and can be restored the normal way

It converts one page at a time, and it never writes anything until you click Convert.

Dark mode

The macro follows whatever theme the reader has set in Confluence, including diagram colours. Nothing to configure.

Pricing

Free for instances of up to 10 users. Above that it is billed per user through Atlassian, annually. Same app and same features at every tier — nothing is held back from the free version.

Privacy

The app makes no network calls outside Atlassian and declares no external egress. There is no server of ours, no analytics and no telemetry. Everything renders in your own browser. See the privacy policy for detail.

Troubleshooting

A diagram shows an error instead of a picture. Mermaid rejected the syntax. The error text names the line. Mermaid's own live editor at mermaid.live is the fastest place to check a diagram in isolation.

A diagram is slow the first time. The diagram engine is loaded on demand, so the first diagram on a fresh page load takes a moment and shows a placeholder while it draws. Later ones are immediate.

An image does not appear. Confluence blocks images from hosts it does not trust. The macro shows a small marker rather than failing silently. Attach the image to the page and use its attachment URL.

The converter says it found nothing. It only matches code blocks whose language is set to mermaid. A block with no language set, or set to something else, is left alone deliberately.
