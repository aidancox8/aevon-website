Privacy Policy

Mermaid, Markdown & LaTeX for Confluence · Effective 30 August 2026

Summary

This app does not collect, transmit, or store your data anywhere outside Atlassian. There is no server of ours for it to be sent to.

Where the app runs

The app is built on Atlassian Forge and runs entirely inside Atlassian's own infrastructure. It makes no network requests to any host outside Atlassian, and it declares no external egress permissions. This is verifiable: an app that requested outbound network access would have to declare it in its manifest, and Atlassian would show that on this listing.

What the app reads

Macro content. When you insert the macro and type into it, what you type is stored by Confluence as part of your page, in the same way any other macro parameter is. The app reads it back to render it. It is never copied anywhere else.

Page content, only when you ask. The "Convert mermaid code blocks" action reads the page you run it on and writes a converted version back to that same page. It runs only when you explicitly choose it from the page menu. It reads nothing at any other time, and it touches no page other than the one you are on.

The app requests two permissions, both narrowly for that feature:

Permission Why
read:page:confluenceRead the current page to find mermaid code blocks
write:page:confluenceSave the converted page as a new version

What the app does not do

  • No analytics, telemetry, usage tracking, or crash reporting
  • No cookies and no browser storage
  • No third-party services in the rendering path
  • No account, no sign-up, and no personal data collected
  • Nothing sent to the developer, ever

Diagrams, Markdown, code and maths are all rendered in your own browser.

Data retention

The app retains nothing, because it stores nothing. All content stays in your Confluence instance under Atlassian's own data residency and retention terms. Uninstalling removes the app; your pages and their content are unaffected.

Sub-processors

None.

Changes

If this policy changes in a way that affects what the app reads or transmits, the listing will be updated before the change ships.
